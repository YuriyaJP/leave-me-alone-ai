# Leave Me Alone Agent

Work behaviour: applications, activity, work hours, context switching and other local signals
Calendar & tasks: understanding commitments, workload and priorities
Local AI: interpreting work context while keeping personal data local where possible
Task prioritisation: deciding what can wait, what can be handled, and what needs attention
Agent actions: eventually handling routine work on the user's behalf
Protected time: enabling modes such as weekends, evenings and holidays where the agent manages incoming work and minimises interruptions
